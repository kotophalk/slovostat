# Конфигурация

Все настройки читаются из переменных окружения при старте
([`app/config.py`](../app/config.py)).

| Переменная | По умолчанию | Описание |
|---|---|---|
| `SLOVOSTAT_RATE_LIMIT` | 25 | Лимит запросов в день на IP |
| `SLOVOSTAT_TIMEOUT` | 10 | Таймаут загрузки страницы (сек) |
| `SLOVOSTAT_DB_PATH` | slovostat.db | Путь к SQLite базе |
| `SLOVOSTAT_MAX_PAGE_MB` | 5 | Максимальный размер страницы (МБ) |
| `SLOVOSTAT_TRUSTED_PROXIES` | localhost + приватные сети | Адреса, от которых принимается `X-Forwarded-For` |
| `SLOVOSTAT_ALLOW_PRIVATE_TARGETS` | 0 | Разрешить анализ приватных адресов |

## Какие ссылки принимаются

- Только `http://` и `https://`.
- Только публичные адреса: localhost, приватные сети, link-local (в том числе
  `169.254.169.254`) и прочие служебные диапазоны отклоняются. Это защита от
  SSRF — без неё сервис ходит по любому адресу внутренней сети от своего имени.
- Не больше 5 редиректов, адрес проверяется на каждом шаге.
- Только HTML или текст; PDF и прочие бинарные ответы отклоняются.
- Загрузка обрывается на `SLOVOSTAT_MAX_PAGE_MB`, если сервер прислал больше.

Лимит запросов списывается и при неудачной загрузке — иначе перебор URL не
стоил бы ничего.

`SLOVOSTAT_ALLOW_PRIVATE_TARGETS=1` снимает проверку адресов. Это только для
локальной разработки: на публичном сервере флаг открывает доступ во внутреннюю
сеть.

## IP клиента за reverse proxy

`request.client.host` за прокси всегда равен адресу прокси, поэтому реальный IP
берётся из `X-Forwarded-For`. Заголовок принимается только если запрос пришёл с
адреса из `SLOVOSTAT_TRUSTED_PROXIES`; цепочка обходится справа налево, и
берётся первый адрес, который не принадлежит доверенным сетям. Значения, которые
клиент подставил сам, остаются левее и не влияют на результат.

По умолчанию доверенными считаются `127.0.0.1`, `::1` и приватные сети
(`10/8`, `172.16/12`, `192.168/16`, `fd00::/8`) — этого хватает и когда прокси
стоит на хосте, и когда он в соседнем контейнере. Формат — список через запятую,
допускаются и отдельные адреса, и подсети:

```bash
SLOVOSTAT_TRUSTED_PROXIES=127.0.0.1,10.8.0.0/24
```

Если приложение выставлено наружу без прокси, задай пустое значение —
`X-Forwarded-For` будет игнорироваться полностью.
